Документація API — Спортивна ліга (Варіант №20)
Цей документ описує базовий контракт взаємодії з власним REST-подібним API на PHP без використання фреймворків.

Базовий URL: http://localhost/practicum06/api.php

Формат відповіді: application/json

Загальна структура успішної відповіді: {"success": true, "data": [...]}

Загальна структура помилки: {"success": false, "error": "Опис помилки"}

Ресурси та маршрути
1. Отримати список усіх команд
Метод: GET

URL: ?resource=teams

Опис: Повертає масив усіх команд, відсортованих за кількістю очок.

Коди статусу:

200 OK — Успішно.

Приклад відповіді:

JSON
{
    "success": true,
    "data": [
        {"id": 1, "name": "Динамо", "city": "Київ", "points": 40},
        {"id": 2, "name": "Шахтар", "city": "Донецьк", "points": 35}
    ]
}

2. Отримати одну команду за ID
Метод: GET

URL: ?resource=teams&id={id}

Опис: Повертає інформацію про конкретну команду за її ідентифікатором.

Коди статусу:

200 OK — Команду знайдено.

404 Not Found — Команду з таким ID не знайдено.

Приклад відповіді (успіх):

JSON
{
    "success": true,
    "data": {"id": 2, "name": "Шахтар", "city": "Донецьк", "points": 35}
}

3. Створити нову команду
Метод: POST

URL: ?resource=teams

Опис: Додає нову команду до бази даних.

Обов'язкові поля (в тілі запиту body або $_POST): name, city.

Коди статусу:

201 Created — Команду успішно створено.

400 Bad Request — Відсутні обов'язкові поля.

Приклад відповіді (успіх):

JSON
{
    "success": true,
    "data": {"id": 3, "name": "Зоря", "city": "Луганськ", "points": 0}
}

4. Доменна дія: Нарахувати очки команді
Метод: POST

URL: ?resource=teams&action=addPoints&id={id}

Опис: Збільшує кількість очок команди за результат матчу.

Обов'язкові поля в тілі запиту: points (кількість очок для додавання).

Коди статусу:

200 OK — Очки успішно нараховано.

400 Bad Request — Не вказано або некоректно передано параметр points.

404 Not Found — Команду з таким ID не знайдено.

Приклад відповіді (успіх):

JSON
{
    "success": true,
    "message": "Очки успішно нараховано"
}
Обробка помилок та статусів
Якщо надіслано невідомий ресурс або метод запиту не збігається з очікуваним, API повертає відповідні HTTP-статуси (404 Not Found або 405 Method Not Allowed) у форматі JSON.
